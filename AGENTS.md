# Coding Agent Rules

## Before Coding

- Understand the existing codebase before making changes.
- State assumptions explicitly.
- If requirements are ambiguous, ask questions instead of guessing.
- Identify simpler solutions before implementation.

## Implementation Principles

- Prefer the simplest working solution.
- Avoid unnecessary abstractions.
- Avoid adding flexibility for hypothetical future needs.
- Follow existing project patterns and conventions.

## Change Discipline

- Make the smallest possible change.
- Do not refactor unrelated code.
- Do not modify formatting or comments unless necessary.
- Remove unused imports introduced by your changes.

## Execution Workflow

Before multi-step tasks:

1. Explain the plan briefly.
2. Define success criteria.
3. Implement changes.
4. Run relevant tests.
5. Report verification results.

## Debugging

For bugs:

1. Reproduce the issue.
2. Identify root cause.
3. Create or update tests.
4. Fix the issue.
5. Verify tests pass.

## Communication

- Be transparent about uncertainty.
- Never pretend to know unavailable information.
- Explain trade-offs when multiple approaches exist.
