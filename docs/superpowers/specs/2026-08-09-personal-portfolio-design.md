# 个人作品集网站设计说明

**日期：** 2026-08-09  
**状态：** 待用户审阅  
**范围：** 首版本机演示的个人作品集及本机内容管理，不改动既有售前客户沟通智能体功能。

## 1. 目标与受众

网站同时面向招聘官和潜在客户：在短时间内说明业务价值、解决方案思路和交付能力。首版不公开真实姓名、联系方式或模型密钥，统一采用可替换占位内容。

首批内容包括一个正式案例“售前客户沟通智能体”和两个“即将发布”占位案例；系统必须支持未来新增多个作品。

## 2. 方案选择

评估过三种实现路径：

1. 纯静态页面：视觉实现最快，但不能完成持久化上传与案例管理。
2. 独立作品集应用：边界清晰，但需要额外启动、维护和部署一套程序。
3. **在现有 Node 服务中增加作品集路由与本机管理页：**复用现有启动方式和静态资源服务，支持本地上传发布；以后部署时可替换存储层。**首版采用此方案。**

## 3. 视觉系统

风格为“高级极简”的编辑式科技档案：暖米白背景、深墨黑文字、低饱和铜红仅用于编号、链接与关键状态。使用宽留白、严格网格、细边线和克制的悬停位移；不用厚重阴影、自动播放或炫技式特效。

- 标题：大字号、紧凑行高，建立高级编辑感。
- 正文：易读的无衬线字，控制每行长度。
- 颜色：深色为主信息，铜红为唯一强调，不让案例卡竞争注意力。
- 动效：遵从系统“减少动态效果”偏好；仅为链接、卡片和页面进入提供短而可关闭的过渡。
- 响应式：桌面采用多列网格；移动端收敛为单列，保留完整内容与可触达操作。

## 4. 信息架构

### 4.1 首页

顶部导航包含“作品集”“关于我”“联系”和明显的“进入案例”入口。首屏包含：可替换姓名、定位文案“AI 产品与售前解决方案作品集”、价值主张、本机演示状态和媒介能力提示。

精选案例按编号排列：

1. 售前客户沟通智能体，带一句业务摘要、案例入口和视频入口。
2. 即将发布。
3. 即将发布。

随后展示“能力与交付方式”：业务理解、AI 工作流设计、原型与工程实现、交付演示。页尾预留可替换的邮箱、微信和简历链接。

### 4.2 案例页

每个已发布项目包含以下固定叙事顺序：

1. 编号、项目名称和一句话业务价值。
2. 演示视频封面，用户点击后播放。
3. 挑战：交代原始业务问题。
4. 解决方案：按用户工作流讲述方案。
5. 关键体验：图像或短视频，配文字说明。
6. 交付说明：运行方式、技术与可交付范围。
7. 返回案例列表与下一个案例导航。

“售前客户沟通智能体”首版案例须清楚说明：会前按 A/B/C 阶段生成作战卡、会中动态清单、会后事实确认与 DOCX 输出。展示录制视频与图片，不把 DeepSeek API Key、内部接口或可被滥用的实时调用暴露到作品集。

## 5. 本机内容管理

管理页只用于本机，不出现在对外导航中。它提供临时预览、编辑和确认发布三个阶段：

1. 用户选择图片或视频后，浏览器立即显示临时预览；取消不会写入磁盘。
2. 用户填写项目标题、摘要、角色、时间、业务价值、媒体说明与案例段落。
3. 用户明确点击“发布”后，服务端校验文件与字段，将媒体和案例清单保存到本机；前台自动读取最新案例。

文件限制：JPG、PNG、WebP 和 MP4；图片单文件不超过 20MB，视频单文件不超过 500MB。视频显示封面并在点击后加载播放；图片可放大查看并有替代文本。

已发布案例支持编辑与下架。删除媒体需二次确认；仍被案例引用的媒体禁止删除。媒体和案例元数据随项目目录保存，便于整体备份和迁移。

## 6. 技术边界与数据流

首版复用现有 Node 服务：

```text
本机管理页 → 临时浏览器预览 → 发布 API
                                ↓
                  public/portfolio-media/ + content/portfolio/projects.json
                                ↓
                     作品集首页与案例页（只读展示）
```

管理 API 只接受白名单字段、允许的 MIME 类型与文件大小；文件名由服务端生成，不直接采用上传文件名。案例描述和媒体说明在页面上以文本安全渲染。上传失败、校验失败、磁盘写入失败都保留编辑内容并给出可读提示。

首版不引入账户系统、云数据库、云对象存储、评论、访问分析或公开的实时 AI 体验。未来部署公网时，保留前台数据结构，将本地媒体目录与 JSON 存储替换为对象存储及受保护的管理认证。

## 7. 可访问性、性能与验收

- 所有图片有替代文本，视频有标题和明确播放控件。
- 键盘可完成导航、卡片打开、弹层关闭、上传及发布；状态变化通过可读提示说明。
- 不自动加载大视频；视频点击后才请求，首页使用封面图。
- 移动端、桌面端均能查看案例、播放媒体和完成管理页上传预览。
- 上传限制、类型校验、引用保护、发布后展示和编辑/下架流程均应有自动化测试。
- 既有售前智能体、DeepSeek 接入、作战卡流式优化、DOCX 导出和会议流程必须回归通过。

## 8. 非目标

本设计不包含真实身份信息预填、公开云部署、第三方视频托管、在线支付、访客登录或跨设备同步。这些能力只有在首版本机内容管理稳定后再单独设计。
